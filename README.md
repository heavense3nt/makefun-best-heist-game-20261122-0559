The Gilded Vault — a midnight heist in three acts. Plan each job on its briefing screen, then sneak through a museum, a bank vault and a casino: patrolling guards with vision cones, sweeping security cameras, laser grids, paintings and gems to lift, a vault door to pick, and the star loot to carry out to the getaway van before dawn. Tools cost a decision: EMP bursts to blind the cameras, smoke bombs to break a guard's line of sight. Get spotted and the alarm climbs; hit lockdown and the doors seal. Played with keyboard and mouse, in a desktop browser, from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, Shift to sneak, E to grab and pick, Q for smoke, F for EMP, Space to start, P to pause.
